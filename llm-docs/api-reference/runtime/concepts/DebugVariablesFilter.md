# DebugVariablesFilter

**Type:** Table

## Parameters

### count

When `filter` is "indexed", the size of the requested page.

**Type:** `int32`

**Optional:** Yes

### filter

The kind of filter applied to this request. Default "all".

**Type:** `"indexed"` | `"named"` | `"all"`

**Optional:** Yes

### start

When `filter` is "indexed", the index to start at.

**Type:** `int32`

**Optional:** Yes
