# on_player_color_changed

Called after a player's color changes.

## Event Data

### by_script

**Type:** `boolean`

If the change was done by script or the player.

### name

**Type:** `defines.events`

Identifier of the event.

### old_chat_color

**Type:** `Color`

The old chat color.

### old_color

**Type:** `Color`

The old color.

### player_index

**Type:** `uint32`

The player whose color changed.

### tick

**Type:** `MapTick`

Tick the event was generated.
